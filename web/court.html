        Remote TikTok / multi-function

        Remote seperti MIXIO RB-02 mengirim gerakan sentuh (geser dan ketuk). Geser kiri = tim A, geser kanan = tim B, geser bawah = batalkan, ketuk ♥ = Main.

        Tombol media: ⏮ = Tim A, ⏭ = Tim B, ⏯ = batalkan. Berguna untuk remote yang hanya mengirim play/next.
