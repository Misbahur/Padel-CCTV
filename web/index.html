        Remote TikTok / multi-function

        Remote seperti MIXIO RB-02 tidak mengirim tombol keyboard, tapi gerakan sentuh (geser dan ketuk). Buka mode ini supaya gerakan itu menambah poin. Bawaan: geser kiri = tim A, geser kanan = tim B, geser bawah = batalkan, ketuk ♥ = Main.

        Tombol media: ⏮ = Tim A, ⏭ = Tim B, ⏯ = batalkan. Berguna untuk remote yang hanya mengirim play/next.
